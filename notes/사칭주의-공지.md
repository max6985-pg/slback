# 사칭 주의 공지 (텔레그램 등에 붙여넣기용)

## 전체 버전

📢 [공지] 텔레그램 사칭 주의 안내

최근 저희를 사칭한 텔레그램 계정이 많이 발생하고 있습니다.

✅ 모든 업무 관련 대화는 공식 단체방에서만 진행합니다.
✅ 1:1 개인 메시지로 업무 연락을 드리지 않습니다.

1:1로 연락이 오면 사칭 계정이니 응답하지 마시고 무시해 주세요.

⚠️ 아래 요청은 모두 사칭이니 절대 응하지 마세요.
- "화이트 IP 등록해 드린다"며 요청하는 모든 정보
- OTP 번호, 메신저(텔레그램 등) 인증코드 요청
- 아이디, 비밀번호, API 키 등 계정 관련 중요 정보 요청
- 입금, 송금, 결제 요청
- 상품권·핀번호 전송 요청
- 다른 링크나 방으로 이동하라는 요청

🔒 저희는 어떤 경우에도 OTP, 인증코드, 비밀번호를 요청하지 않습니다.
화이트 IP 등록 같은 설정 변경도 단체방에서 공식적으로 안내합니다.

의심되는 메시지를 받으면 단체방에 바로 알려 주세요.
여러분의 소중한 자산을 지키기 위해 협조 부탁드립니다. 감사합니다.

## 짧은 버전 (고정 메시지용)

🚨 사칭 주의 🚨
업무는 단체방에서만 진행합니다. 1:1 메시지는 모두 사칭입니다.
화이트 IP 등록을 핑계로 OTP·인증코드·중요 정보를 요구하면 절대 알려 주지 마세요.
저희는 OTP, 인증코드, 비밀번호를 절대 요청하지 않습니다.
